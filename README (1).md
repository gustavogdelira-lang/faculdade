# Guardiãs — Ponto de Ajuda camuflado em uma loja de roupas

Demonstração do projeto: um QR Code na cabine do banheiro abre o site de uma loja de roupas. O pedido de ajuda
fica dentro do chat de atendimento, e a equipe recebe o alerta no painel.

Para ver: abra o site publicado (GitHub Pages). Use o botão "Visão da equipe" no topo para ver o painel.

Os alertas desta versão são simulados no navegador. Em risco imediato, ligue 190. Para denunciar violência contra a mulher, ligue 180.
